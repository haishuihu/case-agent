Summary Segment Styles

Three ways to visually separate preconditions / steps / expected result

A

Flow Segments

Each phase in a pill/chip, connected by arrows

验证登录 → 已注册账号，打开登录页 → 输入密码，点击登录 → 跳转管理后台首页
验证密码错误 → 已注册账号，打开登录页 → 输入错误密码，点击登录 → 提示"密码错误"
B

Labeled Inline Segments

Each phase with a tiny label badge, connected by arrows

验证管理员登录 → 前置 已注册账号，打开登录页 → 操作 输入密码，点击登录 → 预期 跳转管理后台首页
验证密码错误提示 → 前置 已注册账号，打开登录页 → 操作 输入错误密码，点击登录 → 预期 提示"密码错误"
C

Segments with Divider Bars

Each phase separated by a thin vertical bar

验证管理员登录 已注册账号，打开登录页 输入密码，点击登录 跳转管理后台首页
验证密码错误提示 已注册账号，打开登录页 输入错误密码，点击登录 提示"密码错误"
