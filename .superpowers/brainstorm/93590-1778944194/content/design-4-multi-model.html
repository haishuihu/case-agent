设计四：多模型适配 + 整体架构总览

一份 prompt 模板，自动适配不同模型的差异

模型差异适配

# prompts/templates/phase4_module_detail.yaml
system_prompt:
default: |
你是一个资深测试设计专家...
overrides:
deepseek: |
# DeepSeek 对角色扮演更敏感，加强角色指令
你现在必须扮演一个资深测试设计专家...
minimax: |
# MiniMax 对输出格式指令需更明确
你是一个资深测试设计专家。重要：你必须只输出 JSON...

适配点 1: System Prompt 格式

DeepSeek 对角色扮演指令更敏感，MiniMax/OpenAI 对格式约束需更明确。每个模型可有自己的 system prompt override。

适配点 2: JSON 输出策略

支持 structured output 的模型用 response_format；不支持的模型在 prompt 中强化 JSON 格式指令。

适配点 3: Token 预算

根据模型 context window 自动裁剪 few-shot 示例数量和知识上下文长度。
